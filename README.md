# Braid Keyboard

A swipe keyboard for Android that reads two thumbs at once. Glide with one thumb, with both, tap, or mix them, in English and Spanish. Everything stays on your phone: Braid has no internet permission.

**[Download the latest version](https://github.com/eddie85u/braidkeyboard/releases/latest)**: open this link on your Android phone and tap `braid.apk`.

## Install
1. Open the link above on the phone and download `braid.apk`.
2. **Samsung only:** turn off Auto Blocker first: Settings → Security and privacy → Auto Blocker → off (you can turn it back on after installing).
3. If Android asks, allow **Install unknown apps** for the app you downloaded it with (Chrome, Files...), then tap **Install**.
4. If Play Protect says the app is unknown, tap **More details → Install anyway**. It warns because Braid isn't on the Play Store yet.
5. Open **Braid** from your apps; its setup turns the keyboard on. Android warns that any keyboard can read what you type: that's the standard warning for every keyboard.

New versions install over the old one and keep everything Braid learned.

## Feedback
In Braid: **Help & about → Send feedback** makes one file with your note and how you type (never your messages), to send however you like. Or write to eddie85+bk@gmail.com.

## Privacy
No internet permission, no accounts, no ads. What Braid learns about your typing stays on the phone until you send it yourself.
